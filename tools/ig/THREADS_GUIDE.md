# Threads 投稿ストックの書き方(キレイネ)

`ig/threads/queue.json` に投稿を足す。GitHub Actions「Threads 投稿」が毎日 8:07 と 21:07(JST)に1件ずつ投稿する。
12:07 は別ワークフローが「今日の最安」画像を投稿するので、ここでは書かない。

## 声・キャラ
- まず tools/ig/VOICE.md を読むこと(AIっぽさを消すルール)。
- 「キレイネの中の人」の一人称。友だちに話すようなタメ口寄りの丁寧語。広告っぽい言い回しはしない。
- 事実は data/*.json(公式サイトの税込通常価格)から取る。数字は「約」「くらい」で丸めてよいが、盛らない。
- 特定院を悪く言わない。効果・安全性を断定しない(「〜こともある」「診察で相談してね」)。ビフォーアフター、体験談のねつ造は禁止。

## Threads で伸びる形(割合の目安)
- poll(アンケート) 3割: 1〜2行の問い + 選択肢2〜4個(各25字以内)。返信が増える。
- text(本音・気づき・小ネタ) 4割: 3〜6行。最後に問いかけで終わると返信が増える。リンクは基本入れない。
- chain(連投スレッド🧵) 3割: 1投稿目は結論か驚きの数字。返信2〜3個で理由を説明。最後の返信にだけ kirei-ne.com のページURLを1つ。
- 各投稿 490 字以内。topic(トピックタグ)は1つ: 美容医療 / 美容皮膚科 / ボトックス / ヒアルロン酸 / リジュラン / 医療脱毛 など。
- 同じ施術が3回続かないように混ぜる。過去の投稿(posted.json)と同じ切り口は避ける。

## 形式
{"id": "t015", "type": "text|poll|chain", "topic": "…", "text": "…", "poll": ["A","B"], "replies": ["…","…"]}
id は連番。足したら長さ・選択肢の文字数を Python で検査してから commit。

## 返信を呼ぶときの書き方
- 「知りたい施術があったら調べます」のような、扱っていない施術まで約束する呼びかけは使わない。
- 呼びかけるときは範囲を示す(例:「ボトックス・ヒアル・リジュランの料金なら答えられます」)。
